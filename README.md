# Menu Driven Calculator

## 1. Objective
To develop a menu-driven calculator using Python 3 that performs basic arithmetic operations.

## 2. Features
- Addition
- Subtraction
- Multiplication
- Division
- Power
- Modulus
- Repeating menu until the user exits
- Input validation and exception handling
- Division by zero prevention
- Results displayed up to two decimal places

## 3. Concepts Used
- Variables and data types
- User input and output
- Conditional statements (if-elif-else)
- While loop
- Functions
- Arithmetic operators
- Exception handling (try-except)

## 4. Program Logic
The program displays a menu containing seven options. The user selects an arithmetic operation and enters two numbers. The corresponding function performs the calculation and displays the result. The menu continues to appear until the user selects Exit.

## 5. Testing
The program was tested with normal values, zero values, invalid numeric inputs, invalid menu choices, and exit functionality.

## 6. Conclusion
The project demonstrates the use of Python functions, loops, conditional statements, arithmetic operators, and exception handling to create a simple calculator application.
